# 调研模板 — R-Series

> **何时用**: 新技术 / 新工具 / 重大变更前,需要先建立事实底 + 知道真相后再动手。
> **不要用**: 已知答案的小问题。
> **配套**: 真实范例见 `../_research/R1-official-docs-overview.md` 到 `R21-bi-design-references.md`。

## 命名规范

`../_research/R<NN>-<topic-slug>.md`,例如 `R22-evidence-studio-rls.md`。

---

## 1. 背景 (Background)

**研究目标**: 一句话,该研究要回答的具体问题。

**触发事件**: 什么导致我做这次调研?例如"用户要 RLS"、"性能慢 30s"。

**研究范围**: 明确"在调研内"和"不在调研内"。

---

## 2. 调研方法 (Methodology)

**数据来源**:
- [ ] 官方文档 / Mintlify (`.md` 后缀路径直接走 curl)
- [ ] GitHub repo / discussions / issues
- [ ] npm registry / PyPI
- [ ] 一手部署案例
- [ ] 社区反模式沉淀

**抓取方式** (从 R1 §顶):

```
mcp__sales-bi-ssh__ssh_exec(cmd="curl -L -A 'Mozilla/5.0' https://docs.evidence.dev/<path>.md")
```

**关键**: Mintlify 文档站支持 `.md` 后缀,直接返回 markdown 而非 SPA HTML。
